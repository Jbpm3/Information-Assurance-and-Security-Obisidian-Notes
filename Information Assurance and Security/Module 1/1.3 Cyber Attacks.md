## 1.3.1 What's the Difference?

**Viruses**
![[Virus.png]]
- replicates and attaches itself to other files.
- requires a host program to run
- can be spread through removable media, internet downloads, email attachments

**Worms**
![[Worms.png]]
- replicates by independently exploiting vulnerabilities in networks
- worms can run by themselves
- do not require user participation 
- can spread very quickly over the network, usually slowing it down.

**Trojan Horse**
![[trojan horse.png]]
- malware that carries out malicious operations by masking its true intent
- might appear legit but very dangerous
- trojans exploit the privileges of the user who runs them

## 1.3.4 Denial of Service (DoS) Attacks

type of network attack that is relatively simple to conduct

result in some sort of interruption to network services

**Two Main Types of DoS attacks**

**Overwhelming quantity of traffic**
![[overwhelming quantity of traffic.png|288]]
- when a network, host or application is ==sent an enormous amount of data== at a rate which it cannot handle
- causes a slowdown in transmission or response, or the device or service to crash.

**Maliciously formatted packets**
![[maliciously formatted packets.png|295]]
![[Packets]]

- When a maliciously formatted packet is sent, the receiver will be unable to handle it.

**Distibuted denial of service (DDoS)**
1. An attacker builds a network (botnet) of infected hosts called *zombies*, which are controlled by handler systems.
2. zombie computers constantly scan and infect more hosts, creating more and more zombies.
3. when ready, the hacker will instruct the handler systems to make the botnet of zombies carry out a DDoS atack.

## 1.3.7 Layer 2 Attacks

![[Layer 2]]

**Spoofing**
- also called *poisoning* 
- type of impersonation attack that takes advantage of a trusted relationship between two systems
![[spoofing.png|438]]

**MAC address spoofing**
- occurs when an attacker disguises their device as a valid one on the network
**ARP Spoofing**
- sends spoofed ARP messages across a LAN
**IP spoofing**
- sends IP packets from a spoofed source address in order to disguise it

**MAC Flooding**
![[MAC flooding.png]]

>Devices on a network are connected via a network switch by using packet switching to receive and forward data to the destination device.

- MAC flooding compromises the data transmitted to a device
- attacker floods the network with fake MAC addresses, compromising the security of the network switch

## 1.3.9 Man-in-the-Middle and Man-in-the-Mobile Attacks

**Man-in-the-Middle**
![[Man-in-the-middle.png|305]]
- happens when a ==cybercriminal takes control of a device without the user's knowledge==
- an attacker can intercept, manipulate, and relay false information between the sender and the intended destination

**Man-in-the-Mobile (MitMo)**
![[man-in-the-mobile.png|300]]
- variation of man-in-the-middle
- used to take control over a user's mobile device
- when infected, the mobile device is instructed to exfiltrate user-sensitive information and send it to the attackers

## 1.3.15 Defending Against Attacks
- Configure firewalls to remove any packets from outside the network that have addresses indicating that they originated from inside the network.
- Ensure patches and upgrades are current.
- Distribute the workload across server systems.
- Network devices use Internet Control Message Protocol (ICMP) packets to send error and control messages, such as whether or not a device can communicate with another on the network. To prevent DoS and DDoS attacks, organizations can block external ICMP packets with their firewalls.
