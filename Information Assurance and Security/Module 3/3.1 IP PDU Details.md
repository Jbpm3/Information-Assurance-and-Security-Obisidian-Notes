## 3.1.2 The IPv4 Packet Header
![[ipv4.png]]

**Version** - 4-bit binary value set to 0100 that identifies this as an IPv4 packet
**Internet Header Length** - 4-bit field containing the length of the IP header
					- min. length of an IP header is 20 bytes
**Differentiated Services or DiffServ (DS)** - formerly called *Type of Service (ToS)* field
			- six most significant bits *Differentiate Services Code Point (DSCP)*
			-last two bits *Explicit Congestion Notification (ECN)* bits
**Total Length** - length of the IP packet
		- total length field is 2 bytes
**Identification, Flag, and Fragment offset** - as an IP packet moves through the internet, it might need to cross a route that cannot handle the size of the packet
		- the packet will be divided, or fragmented, into smaller packets and reassembled later
		- These fields are used to fragment and reassemble packets
**Time-to-Live (TTL)** - 8-bit binary value that is used to limit the lifetime of a packet
**Protocol** - used to identify the next level protocol
		- common values ICMP (1), TCP (6), UDP (17)
**Header checksum** - used to determine if any errors have been introduced during transmission
**Source and Destination IPv4 Address** - 32-bit binary value
								- Source is always a unicast address
**Options and Padding** - This is a field that varies in length from 0 to a multiple of 32 bits.
			-  If the option values are not a multiple of 32 bits, 0s are added, or padded, to ensure that this field contains a multiple of 32 bits

## 3.1.4 IPv6 Packet Header
![[ipv6.png]]

**Version** - 4-bit binary value set to 0110 that identifies this as an IPv6 packet.
**Traffic Class** - equivalent to the IPv4 Differentiated Services (DS) field
**Flow Label** - suggests that all packets with the same flow label receive the same type of handling by routers.
**Payload Length** - indicates the length of all the data portion or payload of the IPv6 packet
**Next Header** - equivalent to the IPv4 Protocol field.
**Hop Limit** - replaces the IPv4 TTL field
		- value is decremented by a value of 1 by each router that forwards the packet
		- When the counter reaches 0, the packet is discarded, and an ICMPv6 Time Exceeded message is forwarded to the sending host, indicating that the packet did not reach its destination because the hop limit was exceeded.
